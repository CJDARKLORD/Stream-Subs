## [1.0.0] — 2026-09-27

Первый публичный релиз.

### Добавлено

**Ядро**
- Локальные live-субтитры RU→EN через Whisper `medium` на CUDA
- VAD-нарезка фраз через Silero VAD
- GPU-ускорение через CTranslate2 (`float16` на CUDA, `int8` на CPU)
- Автоматический fallback на CPU, если CUDA недоступна
- Трансляция субтитров в браузер через WebSocket + FastAPI

**Веб-интерфейс**
- Страница субтитров `/` с прозрачным фоном для OBS/Streamlabs
- Страница настроек `/settings` с живым предпросмотром
- Поддержка Google Fonts (любой шрифт с fonts.google.com)
- Настройка размера, цвета, отступа снизу, ширины, времени показа
- Разбиение длинных фраз на куски (`maxChars`, `chunkTime`)

**Фильтрация**
- Чёрный список галлюцинаций Whisper (`Thank you`, `Bye`, и т.д.)
- Чёрный список запрещённых слов для безопасности эфира
- Регулярные выражения для паттернов (`translated by`, мат как часть слова)
- Словарь мемов и сленга (`slang.txt`)
- Логирование всех распознаваний в `whisper_log.txt` (для аудита)

**Установщик**
- Inno Setup установщик с иконкой и двуязычным README
- Bootstrap-загрузчик: автоматическая установка всех зависимостей
- Встроенный Python 3.11.9 (системный не нужен)
- Автозагрузка ~4 ГБ компонентов при первом запуске (torch, CUDA, модели)
- Автокопирование NVIDIA DLL в `ctranslate2`
- Автозагрузка модели Whisper `medium` (~1.5 ГБ) и Silero VAD (~2 МБ)
- Прогресс с этапами `[1/4]`–`[4/4]`, таймер, проверки интернета и места
- Цветной вывод в консоли (ANSI)

**Документация**
- Двуязычный README (RU + EN) с 4 скриншотами
- MIT-лицензия
- Раздел поддержки проекта в README
- Кнопка Sponsor на GitHub через `FUNDING.yml`

### Технические детали
- Задержка перевода: 0.3–0.7 секунды на фразу (2070 Super, `medium`)
- Размер установщика: ~40 МБ
- Размер после установки и первой загрузки: ~4 ГБ
- Работает на Windows 10/11 (x64)

### Известные ограничения
- Только русский → английский
- Мемы и сленг переводятся не всегда корректно (часть лечится через `slang.txt`)
- Возможны галлюцинации на шуме (фильтр отсекает 99%, но не 100%)
- Минимальная задержка 0.5 секунды из-за ожидания тишины (VAD)
